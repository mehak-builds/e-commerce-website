# E-Commerce Website 🛒

A simple e-commerce website built using HTML, CSS, and JavaScript. This project demonstrates basic online shopping functionality and DOM manipulation.

## ✨ Features

- Product listing
- Add products to cart
- Remove products from cart
- Cart management
- Basic checkout functionality

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Clone or download this repository.
2. Open `e-commerce.html` in your web browser.
3. Browse products and try the cart functionality.
